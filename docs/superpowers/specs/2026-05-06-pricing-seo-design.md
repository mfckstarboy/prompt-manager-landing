# PromptTray Pricing SEO Design

## Goal

Improve the `/pricing` page so it is more indexable for commercial intent queries while keeping PromptTray positioned as a multi-platform AI prompt manager rather than a ChatGPT-only tool.

## Scope

This update covers the existing `/pricing` page only.

It includes:

- stronger pricing-page metadata
- additional crawlable pricing copy below the pricing cards
- clearer explanation of who the free plan is for
- clearer explanation of who Premium is for
- stronger multi-platform messaging across ChatGPT, Claude, Gemini, and Perplexity

It does not include:

- billing logic changes
- checkout changes
- plan limit changes
- design overhaul of the pricing cards

## Positioning

The pricing page should target commercial search intent around AI prompt manager pricing, not just ChatGPT prompt manager pricing.

PromptTray should be described as:

- an AI prompt manager
- a Chrome extension
- a multi-platform prompt workflow for ChatGPT, Claude, Gemini, and Perplexity

If ChatGPT is mentioned, it should appear as one supported tool within the broader multi-platform product positioning.

## Content Additions

Below the pricing cards, add short crawlable sections with natural keyword-bearing headings:

- `AI prompt manager pricing`
- `Who the free plan is for`
- `Who should upgrade to PromptTray Premium`

The copy should explain:

- what the free plan enables
- what changes when a prompt library grows
- why Premium is useful for heavier prompt reuse workflows
- how PromptTray works across multiple AI tools rather than one chatbot

## Writing Direction

Tone should be:

- direct
- practical
- lightly commercial
- specific
- non-hypey

SEO should be explicit but natural. The copy should not read like keyword stuffing.

Preferred phrases:

- AI prompt manager pricing
- prompt library
- save and organize prompts
- works across ChatGPT, Claude, Gemini, and Perplexity
- reusable prompt workflows

## UX Constraints

Keep the current pricing page structure and cards.

The new content should feel like supporting explanation, not a second landing page. It should sit below the cards and help both search engines and buyers understand plan fit.

## Success Criteria

This update is complete when:

- `/pricing` has stronger metadata
- the page includes 150 to 300 words of crawlable supporting copy
- the copy clearly explains free-plan fit and Premium-plan fit
- the page consistently presents PromptTray as multi-platform
- lint and build pass aside from any unrelated pre-existing warnings
