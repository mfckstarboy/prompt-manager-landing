# PromptTray Support SEO Design

## Goal

Expand `/support` from a lightweight contact page into a real help hub that is more indexable for support and setup queries while keeping PromptTray positioned as a multi-platform AI prompt manager.

## Scope

This update covers the existing `/support` page only.

It includes:

- stronger support-page metadata
- additional crawlable support content
- setup guidance
- account connection guidance
- sync and access guidance
- troubleshooting guidance
- a stronger FAQ block
- helpful internal links to core pages and guides

It does not include:

- backend support tooling
- live chat
- ticket forms
- screenshots
- a separate docs center

## Positioning

The support page should target queries like:

- PromptTray support
- how to set up PromptTray
- how to connect prompt extension account

PromptTray should be described as:

- an AI prompt manager
- a Chrome extension
- a workflow that works across ChatGPT, Claude, Gemini, and Perplexity

Support language should stay multi-platform. ChatGPT can be mentioned as one of the supported tools, but the page should not read as if the product only exists for ChatGPT.

## Content Structure

Keep the current shell, but expand the page into a help hub with sections such as:

- `PromptTray support`
- `How to set up PromptTray`
- `How to connect your extension account`
- `Prompt syncing and account access`
- `Troubleshooting PromptTray`
- `Contact support`

The FAQ section should include practical, search-style questions users are likely to type directly into search.

## Writing Direction

Tone should be:

- helpful
- direct
- calm
- practical
- non-salesy

The page should read like real support documentation, not product marketing copy.

SEO should be explicit but natural. The content should make it easy for search engines to understand what support topics the page covers.

## Internal Linking

Include helpful links where relevant to:

- `/`
- `/pricing`
- `/guides/save-prompts-in-chatgpt`
- `/guides/organize-ai-prompts`
- `/guides/manage-prompts-across-ai-tools`

Links should support the user journey rather than being added mechanically.

## Success Criteria

This update is complete when:

- `/support` has stronger metadata
- the page clearly covers setup, login/account connection, sync, troubleshooting, and contact
- the FAQ is more substantial and search-oriented
- the page consistently presents PromptTray as multi-platform
- lint and build pass aside from unrelated pre-existing warnings
