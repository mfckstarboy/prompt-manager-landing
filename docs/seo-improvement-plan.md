# SEO Improvement Plan

Last updated: May 6, 2026

## Objective

Grow organic traffic for `prompttray.app` by moving from a mostly single-page product presence into a focused search footprint around prompt management, ChatGPT workflows, and AI prompt organization.

The technical indexing blockers were addressed on May 6, 2026:

- `prompttray.app` now permanently redirects to `https://www.prompttray.app/`
- the sitemap is live and resubmitted in Google Search Console
- `/pricing` is indexable
- utility pages such as `/demo`, `/sign-up/success`, and `/upgrade/success` are noindexed

The next stage is improving relevance, page depth, internal linking, and topical coverage.

## Primary SEO Themes

Primary topic:

- AI prompt manager

Supporting topics:

- ChatGPT prompt manager
- prompt library
- save and organize prompts
- Chrome extension for prompts
- organize AI prompts
- manage prompts across ChatGPT, Claude, and Gemini

## Success Criteria

Near-term success signals:

- `/pricing` becomes indexed
- `/support` becomes indexed
- Google starts showing impressions for non-brand queries
- more than the homepage begins earning impressions in Search Console

Longer-term success signals:

- guide pages get indexed and begin generating impressions
- prompt-related commercial and informational queries begin surfacing in GSC
- CTR improves on homepage and pricing pages

## Phase 1: Strengthen Existing Pages

Timeline: 1 to 2 weeks

### 1. Improve the homepage for one clear topic

Target theme:

- AI prompt manager for ChatGPT, Claude, and Gemini

Recommended improvements:

- Make the H1 more explicit
- Ensure the first 100 words clearly describe the product and use case
- Reinforce search themes in section headings
- Add a short FAQ section
- Add stronger internal links to `/pricing` and `/support`

Suggested homepage direction:

- H1: `AI Prompt Manager for ChatGPT, Claude, and Gemini`
- Supporting copy should emphasize saving, organizing, reusing, and syncing prompts across tools

### 2. Improve indexable commercial pages

Priority pages:

- `/pricing`
- `/support`

#### `/pricing`

Recommended improvements:

- Add 150 to 300 words of crawlable copy
- Explain who the free plan is for
- Explain who the premium plan is for
- Explain the pain solved by upgrading
- Add a clear feature comparison section if the text is currently thin

Suggested search intent:

- Prompt manager pricing
- ChatGPT prompt manager pricing

#### `/support`

Recommended improvements:

- Expand it into a real help hub
- Add keyword-bearing headings
- Cover setup, login, extension connection, sync, and troubleshooting
- Add FAQ-style sections users actually search for

Suggested search intent:

- PromptTray support
- how to set up PromptTray
- how to connect prompt extension account

### 3. Request indexing in Google Search Console

Request indexing for:

- `/pricing`
- `/support`
- `/privacy`
- `/terms`
- `/refund`

- `/guides/chatgpt-prompt-library`

## Phase 3: Build Authority

Timeline: 1 to 2 months

### 1. Acquire relevant backlinks

Best early opportunities:

- Chrome extension directories
- AI tool directories
- indie product listings
- founder interviews
- product roundups
- articles about ChatGPT workflows, prompt engineering, or AI productivity

### 2. Publish comparison and alternatives pages

Suggested examples:

- `PromptTray vs Notion for prompt management`
- `PromptTray vs spreadsheet prompt libraries`

These pages can perform well because they target users already comparing solutions.

### 3. Add trust and conversion signals

Recommended additions:

- screenshots
- step-by-step setup visuals
- real use cases
- testimonials if available
- clear differentiators from generic note-taking or document tools

## Suggested Information Architecture

Core pages:

- `/`
- `/pricing`
- `/support`

Guides:

- `/guides/...`

Comparisons:

- `/compare/...`

Use cases:

- `/use-cases/...`

This structure helps Google understand the topical clusters of the site instead of treating the product as a single isolated landing page.

2. Improve `/pricing`
